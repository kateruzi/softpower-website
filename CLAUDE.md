# softpower-website — dashaprostova.com

Личный сайт Даши Простовой: статические страницы (nginx) + сервис магазина мерча
(`shop/`, Python + Postgres, оплата через Stripe).

## Окружения и деплой

- **Только prod, staging нет** — решение от 2026-10-26: сайт правит сама Даша через
  своих агентов, промежуточный контур никому не нужен. Это осознанное отступление от
  общего правила prod+staging.
- **Любой push в `main` автоматически уходит в прод** в течение минуты.
- Схема pull: на сервере `site-autodeploy@dashaprostova.timer` раз в минуту делает
  `git fetch` и выкатывает новый `main` скриптом `/usr/local/bin/site-autodeploy`.
  GitHub Actions и SSH-ключей для деплоя нет — у GitHub нет доступа к серверу.
- Что скрипт делает сам: дамп базы магазина перед выкаткой изменений в `shop/`,
  `docker compose up -d --build`, reload nginx, проверку `/` и `/api/health`,
  откат на прежний коммит при неудаче, тег `release-ГГГГ.ММ.ДД[-N]` при успехе,
  алерт в общий Telegram-канал при любой проблеме.
- Что скрипт **не** выкатывает: изменения `docker-compose.yml` (через него можно
  получить доступ ко всему хосту) — их деплоит человек вручную после ревью; и любые
  коммиты, пока в `/opt/softpower/softpower-website/prod` есть незакоммиченные правки.
- Откаченный коммит повторно не пробуется: нужно запушить исправление.
- Лог: `/var/log/site-autodeploy-dashaprostova.log`.

## Данные

- База магазина (заказы) — volume `softpower-website-prod_shop_pgdata`.
- Регулярных бэкапов базы нет, уровень надёжности ещё не согласован. Есть только
  дампы перед деплоем изменений `shop/`: `/var/backups/softpower-website/`, последние 7.
